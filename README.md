# CPVC Startup Site Template

A one-page website for a made-up app, built by a team of 2 to 4.

| File | Who edits it |
|---|---|
| `sections/hero.js` | Person A |
| `sections/features.js` | Person B |
| `sections/team.js` | Person C |
| `sections/signup.js` | Person D |
| `site.js` | Everyone (app name, tagline, color) |
| `index.html` | Nobody |

**Preview:** double-click `index.html` to open it in your browser. No server needed.

**Rules:** never push to `main`. Make a branch, open a pull request, and have a teammate approve it.
